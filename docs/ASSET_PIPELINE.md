# Asset pipeline

PPC source is pinned to `a2207c4bd6f1be51d426684cf58f11668def7579`. The original 60-file engine-independent core is still under `vendor/ppc/Core`; the unmodified Godot runtime, samples and Plantfolk extension are now included. There is one core implementation, compiled both by Godot and the offline exporter.

Native gameplay samples a genome via `CreatureRuntime.Sample`, builds through the original bounded factory cache, and uses `CreatureActor`/`CreatureRenderQueue` for live movement, idle/run/action/hit/rest and rasterization. Saved appearances contain serialized genomes plus generator IDs. The native game is no longer restricted to five baked identities. The workshop supports all nine families, deterministic mutation, live preview and original-format export.

Anatomy metadata determines wings/flight, fins/swimming, arms/grasp eligibility and collision dimensions. Equipment calls original gear genes to render a separate presentation genome; the underlying appearance remains intact. The current biped weapon visual uses PPC's dagger or staff shape: a distinct long-sword shape and family-specific death clips are not claimed. Incapacitation currently uses tinted/resting presentation.

Offline commands:

```
node tools/export-art.mjs                         # preserved reference catalog
node tools/export-art.mjs /tmp/catalog --all --seed=42
node tools/export-art.mjs /tmp/dragon --family=reptile --seed=1337
```

The exporter compiles with the installed .NET 8 C# compiler and framework reference assemblies, without NuGet or a Godot executable. Output includes PNG sheets, upstream clip/direction/pivot metadata, manifest and anatomy metadata. Environment textures remain original PPC generated art. Native copied environment PNGs are derived from this pipeline; no manual editing is required. Regeneration of those native textures can copy matching environment outputs into `game/art/`.

Dungeon text rules are reproducibly packaged in `game/data/dungeon_rules.json`, then unpacked through Godot FileAccess into `user://` before invoking the original System.IO generator. This works with an exported PCK rather than assuming source files exist beside the executable.

Audio is generated by imported gdfxr, with local fixed SFXR parameters, cached AudioStreams and optional WAV export. There are separate cue, ambience and music players. No licensed music library or recorded ambience is bundled; adding that content uses the existing channels.
